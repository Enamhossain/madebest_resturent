## 🌟 Key Highlights
- **Performance Optimized**: Built with Vite and React Query for lightning-fast speeds.
- **Premium Design**: Modern UI with Tailwind CSS, glassmorphism, and smooth animations.
- **Full-Featured Admin**: Complete control over menu items, users, and customer orders.
- **Secure**: Firebase authentication and JWT-protected API communication.

## 🛠️ Tech Stack
- **Frontend**: React, Tailwind CSS, Tanstack Query
- **Routing**: React Router 6
- **Auth**: Firebase
- **API**: Axios with custom interceptors
- **Deployment**: Vercel

## ⚙️ Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
